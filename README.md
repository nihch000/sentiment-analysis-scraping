## 情感分析为什么离不开稳定的数据采集

做情感分析的人都知道，模型再好，喂不进干净、充足的原始文本就是白搭。而原始文本从哪来？绝大多数场景是从网页上抓：

1. **电商评论**——亚马逊、淘宝、京东的商品评价页
2. **社交媒体**——Twitter/X、微博、Reddit 的帖子和回复
3. **论坛和问答**——知乎、Quora、垂直社区的讨论帖

这些平台几乎都有严格的反爬策略。你用 requests裸跑，可能前 50 条能拿到，后面就开始返回空页面或者直接 ban 你的 IP。自建代理池成本高、维护烦，而且不同平台的反爬逻辑还不一样——有的检测请求频率，有的看浏览器指纹，有的上了 Cloudflare 的 JS Challenge。

这就是数据采集 API 存在的意义：你只管发请求、拿 HTML，中间的代理轮换、指纹伪装、验证码处理全交给它。
